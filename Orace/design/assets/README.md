# Fond d'écran

Dépose ici ton image de fond sous l'un de ces noms :

    wallpaper.jpg   wallpaper.jpeg   wallpaper.png   wallpaper.webp

Elle est détectée automatiquement au chargement et remplace le fond dessiné
(dragon SVG + texture carbone). Aucune modification de code n'est nécessaire.

Si aucune image n'est présente, le fond dessiné reste affiché.
